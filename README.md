# E-Zip v0.1
Primeira versão funcional do E-Zip: interface Dark, sidebar retrátil e chat conectado à OpenAI Responses API.

## Rodar
1. Instale Node.js 20+.
2. Na pasta do projeto: `npm install`
3. Copie `.env.example` para `.env` e coloque sua `OPENAI_API_KEY`.
4. Rode `npm start`.
5. Abra `http://localhost:3000`.

A chave fica somente no servidor. O botão de voz está preparado visualmente; Realtime/voz é a próxima etapa.
